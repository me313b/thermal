Marks in text

      

        ==text== highlight; ==r: g: b: p: colours
        ~r:text~ coloured text (r g b p)
        Cmd+Z / Cmd+Shift+Z undo / redo (\u21BA panel on the bar)

        {++ins++} {--del--} {~~a~>b~~} tracked changes
        > [!note] Title callout (warning, success, important)
        - [ ] task \u23F0 2026-07-20T09:00 reminder

        states: ledger a | id | state | rank | table drives \u2713/\u2715 and order

      Sync everywhere with GitHub
      
    

    

      
MB keeps your whole vault (notes, proposals, photos and voice notes) in a private GitHub repository, so every device where you connect stays in sync. When the same note was edited in two places, the newer version wins, exactly like Import.

      

        
        
      

      
One paste, one click: create a token at github.com/settings/tokens with the repo scope, paste it above, press Connect. MB detects your username, creates the private repository if needed, and runs the first sync. The token lives only on this device (encrypted when the vault is encrypted) and is revocable on GitHub at any time. Prefer a fine-grained token? Grant it Contents: Read and write on an existing repo you create yourself.
